Permettre aux clients d'archiver leurs commandes terminées

User story Web Back-office support

Contexte

Les clients réguliers accumulent de nombreuses commandes et leur historique devient difficile à lire. Le support reçoit des demandes pour masquer d'anciennes commandes.

Description

En tant que client, je veux archiver mes commandes livrées ou annulées afin de garder un historique lisible. Je les retrouve dans un onglet « Archivées » et je peux les désarchiver.

Critères d'acceptation

Given{{g.given}} When{{g.when}} Then{{g.then}}

Précisions

  • Rendu : reprendre l'écran « Mes paniers sauvegardés » (onglet dédié, même bouton), sans l'option « Supprimer ».
  • Service client : les commandes archivées restent visibles dans le back-office.
  • Périmètre : web uniquement. L'app mobile fera l'objet d'un ticket séparé.
  • E-mails de suivi : le lien ouvre la commande normalement, même archivée.
